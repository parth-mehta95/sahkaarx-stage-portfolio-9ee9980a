## Task Brief
Write JOIN queries to merge sales transactions with customer and product information for analysis.

## Scenario
Build JOIN queries linking sales, customers, and products. Your manager needs customer purchase history reports.

- Sample output showing joined customer and sales data

## Success Criteria
- All JOIN types execute correctly
- Results include all required columns from joined tables
- Queries handle NULL values appropriately
