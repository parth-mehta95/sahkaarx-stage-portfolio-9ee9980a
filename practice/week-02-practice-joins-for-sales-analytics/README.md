# Practice JOINs for Sales Analytics

## Task Brief
Write JOIN queries combining sales, customers, and products tables for comprehensive analysis.

## Scenario
Build JOIN queries linking sales, customers, and products. Your team needs customer purchase history reports with product details.

## Deliverables
- join_analytics.sql with INNER, LEFT, FULL JOINs
- Query output showing joined customer and sales data

## Success Criteria
- All JOIN types implemented correctly
- Queries return expected combined records
- No NULL values in critical fields
